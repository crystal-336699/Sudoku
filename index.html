First-time Setup
Connect to Firebase
This app needs Firebase to save accounts and battle rooms across any device. Setup takes 2 minutes and is completely free.
1. Go to console.firebase.google.com
2. Create project → Add app → Web (</>)
3. Copy your firebaseConfig values below
4. In Firebase console → Build → Realtime Database → Create
5. Set Rules to { "rules": { ".read": true, ".write": true } }
Config is saved in your browser — you only do this once per device.
